# Skills instaladas neste projeto

- `ui-ux-pro-max/`, `ui-styling/`, `design/`, `design-system/`, `brand/`, `banner-design/`, `slides/`
  Pacote de skills de design (UI/UX, estilos, paletas, tipografia, gráficos e guidelines por stack).
  Fonte: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill (MIT — ver `ui-ux-pro-max-skill.LICENSE`).

- `copy-lp-vendas/`
  Skill para escrever copy de landing page de vendas (infoproduto ou serviço/sistema),
  em 15 blocos nomeados + autoavaliação por rubrica.
